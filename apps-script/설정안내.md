# 작전 저장소 설정 안내 (한 번만)

PC에서 하시는 게 편해요. 15분 정도 걸려요.

## 1. 시트 만들기
1. 구글 드라이브에서 **새 구글 시트**를 만들고 이름을 `공간작전판 작전 저장소`로 바꿉니다.
2. 위 메뉴 **[확장 프로그램 > Apps Script]**를 엽니다.
3. 원래 있던 코드를 모두 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여 넣은 뒤 **저장(💾)**합니다.

## 2. 처음 설정
1. 시트 탭으로 돌아와 **새로고침**하면 위 메뉴에 **[작전판]**이 생겨요.
2. **[작전판 > 처음 설정]** → 권한 확인 창이 뜨면
   - 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **[고급] → [(프로젝트 이름)(으)로 이동]** → **[허용]**
   - 선생님 계정의 이 시트만 쓰는 코드라 괜찮아요.
3. 창에 나온 **교사 열쇠**(영문·숫자 10자리)를 적어 둡니다. 나중에 [작전판 > 교사 열쇠 보기]로 다시 볼 수 있어요.
4. **[작전판 > 조 비밀번호 만들기]** → `11,6` 입력 → [조] 시트에 반·조·비밀번호가 생겨요.
   - 조가 5개인 반은 그 반의 6조 줄을 지우면 됩니다.
   - 비밀번호는 직접 바꿔도 돼요(숫자 4자리, 1000~9999).

## 3. 웹 앱으로 배포
1. Apps Script 화면 오른쪽 위 **[배포 > 새 배포]**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 다음 사용자로 실행: **나** / 액세스 권한이 있는 사용자: **모든 사용자**
4. **[배포]** → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 작전판에 연결
- 웹 앱 URL을 Claude에게 보내 주시면 작전판 파일에 넣어 드려요. 그러면 **모든 태블릿이 따로 설정 없이** 바로 연결돼요.
- 직접 해 보시려면: 작전판 **⚙ > 작전 저장소 주소**에 붙여 넣기 (이 방법은 태블릿마다 해야 해요).

## 5. 확인
선생님 태블릿에서 작전판 **⚙ > 교사 화면 열기** → 교사 열쇠 입력 → **[연결 점검]**
`연결됐어요 · 조 66개 · 교사 열쇠 맞음`이 나오면 끝이에요.

---

## 쓰면서 알아 두실 것
- **제출 마감**: [설정] 시트의 `제출마감` 칸에 `8,9`(8반·9반) 또는 `all`(전체)을 적으면 그 반은 저장이 막히고 불러오기만 돼요. 비우면 다시 열려요.
- **잘못 낸 작전 숨기기**: [작전] 시트에서 그 줄의 `숨김` 칸을 `TRUE`로 바꾸면 없는 것으로 칩니다. 지우지 않아도 돼요.
- **비밀번호를 5번 틀리면** 그 조는 5분 동안 잠겨요.
- 학생 이름은 어디에도 저장되지 않아요. 조원 명단은 선생님이 따로 관리하세요.
- **코드를 고쳤을 때 주의**: [새 배포]를 누르면 주소가 바뀌어요. 고친 뒤에는 **[배포 > 배포 관리 > ✏️ 수정 > 버전: 새 버전 > 배포]**로 올려야 주소가 그대로예요.
